# Templates

| Template | Use it for |
| --- | --- |
| [metric-contract.md](metric-contract.md) | One-page Metric Contract for a number and its perspective |
| [definition-contract.md](definition-contract.md) | One-page Definition Contract for a business term (e.g., Customer) and its perspectives |
| [resolution-table.csv](resolution-table.csv) | The answer table: which perspective applies in which context, and when to ask. Fill it in a spreadsheet. Technical teams can convert it with `python reference/tools/smf.py import-csv templates/resolution-table.csv` |
