# Templates

| Template | Use it for |
| --- | --- |
| [metric-contract.md](metric-contract.md) | One-page Metric Contract for a number and its perspective |
| [definition-contract.md](definition-contract.md) | One-page Definition Contract for a business term (e.g., Customer) and its perspectives |
| [answer-table.md](answer-table.md) | The answer table: which perspective applies in which situation, and when to ask |
| [resolution-table.csv](resolution-table.csv) | The same answer table as a spreadsheet file, for technical teams who want to load it into tools. See the [reference](../reference/README.md) |
