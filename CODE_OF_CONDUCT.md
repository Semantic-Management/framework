# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

In short: be respectful, assume good intent, critique ideas rather than people, and keep discussion focused on making the framework and spec better.

Report concerns privately to the maintainer through GitHub: [open a private report](https://github.com/Semantic-Management/framework/security/advisories/new) and say it is a Code of Conduct concern. Only the repository maintainers can see it.
